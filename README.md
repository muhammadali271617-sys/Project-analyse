# Проверка счёт-фактур

Программа открывает каждый PDF-файл счёт-фактуры (Didox.uz) в папке и проверяет,
совпадает ли **номер счёт-фактуры внутри PDF** с **именем файла**.

При сравнении:
- большие и маленькие буквы не различаются (`S2991` = `s2991`);
- `/` и `.` считаются одинаковыми (`543/2` = `543.2`);
- лишние пробелы игнорируются.

## Установка (один раз)

1. Установите Python 3.10+ с https://www.python.org (при установке отметьте **Add Python to PATH**).
2. В командной строке, в папке с программой:
   ```
   pip install -r requirements.txt
   ```

## Запуск

```
python check_invoices.py "D:\all factures for price analyses"
```

Результат:
- в консоли — строка по каждому файлу (✔ совпало / ✘ проблема) и итог;
- Excel-отчёт `отчет_проверки.xlsx` в той же папке с PDF
  (зелёный — OK, красный — не совпадает, жёлтый — номер не найден / файл не читается).

Свой путь для отчёта: `-o "D:\отчет.xlsx"`.

## HTML-версия (без установки)

Файл **`proverka_faktur.html`** — та же проверка прямо в браузере, ничего ставить не нужно.

1. Откройте `proverka_faktur.html` двойным щелчком (Microsoft Edge или Google Chrome).
2. Первый раз нажмите **«Выбрать папку с фактурами»** и разрешите доступ.
3. Программа запомнит папку. В следующие разы достаточно нажать **«Проверить»**
   (браузер может ещё раз спросить разрешение на чтение папки).
4. **«Скачать отчёт Excel»** — сохраняет `отчет_проверки_ДД.ММ.ГГГГ.xlsx`.

Проверяются только PDF прямо в выбранной папке, подпапки не учитываются.
Работает полностью офлайн, файлы никуда не отправляются.

Пересборка HTML (только для разработчика): `html/template.html` — исходник,
`python html/build_html.py --libs <папка с node_modules>` встраивает pdf.js 3.11.174 и ExcelJS 4.4.0.

## Сверка Excel с фактурами — `sverka.py`

Берёт «цветные» строки листа `<месяц>_проверка` / `<месяц>_разницалар`
(Разница AM вне пределов AO/AP, без импорта), находит фактуру по номеру (R) и договору (Q),
находит в ней позицию по названию и числам и сравнивает Кол-во (H), Цену (I), Сумму (J).

```
python sverka.py "D:\папка с Excel и фактурами"
```

Программа спросит период (один месяц или несколько) и сохранит HTML-отчёт
`отчет_сверки_<лист>.html` со всеми проблемными кодами: перепутанные строки, ошибки
кол-ва/цены/суммы, цены с НДС, другие единицы измерения, дубли, дробные штуки,
история цен кода с листа «… (значение)», список недостающих фактур.

Кроме отчёта создаётся копия Excel `<имя>_проверено.xlsx` (исходный файл не меняется).
В проверенных строках заполняются колонки:

| AV | AW | AX | AY | AZ | BA | BB–BG | BH | BI | BJ–BL | BM |
|---|---|---|---|---|---|---|---|---|---|---|
| статус | описание | проблема коротко | название в фактуре | ИСТИНА/ЛОЖЬ (похожесть ≥ 50%) | похожесть, % | цены кода по всем приходам: кол-во, мин, макс, средняя, медиана, отклонение строки | файл и позиция | ед. изм. в фактуре | кол-во, цена, сумма из фактуры | формула =И(ОКРУГЛ(H;2)=ОКРУГЛ(BJ;2);…) |

Формулы, условное форматирование, фильтры и остальные листы копируются без изменений;
фильтр листа расширяется на новые колонки, чтобы можно было фильтровать по статусу.


## Запуск через страницу в браузере — `start.pyw`

Двойной щелчок по `start.pyw` (без чёрного окна) запускает локальный сервер на 127.0.0.1
и открывает страницу в Edge: выбор папки и периода, кнопка «Проверить» с прогрессом,
итоги, таблица проблемных строк с фильтром и поиском, кнопки «Открыть Excel» / «Открыть отчёт»,
кнопка «Завершить». Всё офлайн, только стандартная библиотека Python.

В одной папке должны лежать: `start.pyw`, `start_page.html`, `sverka.py`, `excel_writer.py`.

### Ярлык на рабочем столе
1. Правой кнопкой по `start.pyw` → **Показать дополнительные параметры** (Windows 11) →
   **Отправить** → **Рабочий стол (создать ярлык)**.
2. Переименуйте ярлык, например «Сверка с фактурами».
3. Если по двойному щелчку `start.pyw` открывается в редакторе, а не запускается:
   правой кнопкой по ярлыку → **Свойства** → в поле **Объект** напишите
   `pyw "D:\путь\к\start.pyw"` (или `pythonw "D:\путь\к\start.pyw"`), в поле **Рабочая папка** — папку программы.
4. Значок: **Свойства** → **Сменить значок…** — любой из `C:\Windows\System32\shell32.dll`.

## Ошибки по бухгалтерам — `po_buhgalteram.py`

Из проверенной копии `…_проверено.xlsx` создаёт новую книгу: у каждого бухгалтера
(колонка X «Ответственный») свой лист — точная копия листа проверки (оформление, ширины,
скрытые/сгруппированные колонки, условное форматирование AM, автофильтр A4:BM) только с его
строками, где заполнена «Проблема» (AX) и дата (Z) в выбранных месяцах. Листы по убыванию
числа строк, формулы BM переписаны на новые номера строк, в конце — автоматическая проверка.

- На странице `start.pyw`: шаг 4 «Ошибки по бухгалтерам» — выбрать месяцы и нажать кнопку.
- Из командной строки: `py po_buhgalteram.py "…_проверено.xlsx"` (спросит месяцы) или
  `--month 2026-10`, `--month 2026-09,2026-10`, `--month все`.
