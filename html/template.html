Проверка счёт-фактур

Номер счёт-фактуры внутри каждого PDF сравнивается с именем файла. Файлы никуда не отправляются — всё работает только на этом компьютере.

Выберите папку, в которой лежат PDF-файлы счёт-фактур. Проверяются только PDF в самой папке, подпапки не учитываются.
